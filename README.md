# Yilmaz CNC610 — Android APK

Готовый минимальный проект Android (WebView) со встроенным `визуализаторС3-v3-mobile.html` и автосборкой APK через GitHub Actions.

## Как получить готовый APK за 2 минуты

1. Создайте новый репозиторий на GitHub (публичный или приватный).
2. Распакуйте этот архив и загрузите все файлы в корень репозитория (важно, чтобы папка `.github/workflows/build-apk.yml` оказалась в корне).
3. Перейдите во вкладку **Actions** в репозитории → выберите запуск **Build Android APK** (или нажмите **Run workflow**).
4. После завершения сборки (~2 минуты) скачайте готовый файл **`Yilmaz-CNC610-Visualizer-APK`** в блоке **Artifacts** внизу страницы.
5. Распакуйте скачанный артефакт, перекиньте `Yilmaz-CNC610-Visualizer.apk` на смартфон и установите.

## Что поддерживается в APK

- Открытие локальных файлов `.mdb`, `.csv`, `.txt` и фотографий профиля через системный проводник Android (`onShowFileChooser`).
- Автономный разбор баз Jet 4.0 (`.mdb`) прямо внутри приложения без интернета.
- Полноэкранный режим (`IMMERSIVE_STICKY`) и сохранение состояния при повороте экрана.
- Защита от случайного закрытия — выход по двойному нажатию «Назад».
- Разрешён HTTP-трафик в локальной сети (`usesCleartextTraffic="true"`).
